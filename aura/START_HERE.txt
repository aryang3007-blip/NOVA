================================================================
  A U R A  —  local setup
================================================================

  1. Install Ollama            https://ollama.com/download
  2. ollama pull gemma2:2b
  3. pip install psutil        (optional: live CPU/RAM readings)
  4. python serve.py --allow-actions

  Opens http://localhost:8000 automatically.

  Do NOT open index.html directly — browsers block camera, mic
  and ES modules on file://. The server provides localhost,
  which browsers treat as a secure context.
